    VersionReleasedType InstallsShare First 7 days GitHub downloads

    What an install is. Obsidian counts downloads of each plugin version. Someone who updates to a newer version counts again, so these are not unique users. Obsidian does not publish a time series, so daily and monthly numbers come from this site's own daily snapshots of the public stats file. Each snapshot reflects the state at about 00:30 UTC, so installs are credited to the previous day.
